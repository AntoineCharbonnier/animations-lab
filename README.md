# Animation Lab

Expérimentation d'interface de sélection interactive : boutons directionnels (haut/bas/gauche/droite) déclenchant des timelines GSAP (`TimelineMax`) choréographiées en DOM/SVG.

## Stack

- GSAP (TweenMax/TimelineMax) pour le séquencement d'animations
- ES6 via Babel/Browserify (gulp)

## Installation

```
npm install
gulp server
```
